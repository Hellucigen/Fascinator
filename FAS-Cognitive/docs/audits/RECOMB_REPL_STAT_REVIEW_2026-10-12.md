## 1. 数学核验过程（手工推导 + 精确计算交叉验证）

### 1.1 双侧精确符号检验 n=6 的全部可达 p 值

零假设下非平局题的正负号 ~ Bin(n, 0.5)，双侧 p = 2·P(X ≥ x_obs)（封顶 1）：

| 非平局题数 | 同向 x | 单侧尾概率 | **双侧 p** | 未校正 0.05？ |
|---|---|---|---|---|
| 6 | 6/6 | 1/64=0.015625 | **0.031250** | 是（唯一情形） |
| 6 | 5/6 | 7/64=0.109375 | **0.218750** | **否** |
| 5 | 5/5 | 1/32 | 0.062500 | 否 |
| 4 | 4/4 | 1/16 | 0.125000 | 否 |
| 3 | 3/3 | 1/8 | 0.250000 | 否 |
| 2 | 2/2 | 0.500000 | 否 |
| 1 | 1/1 | 1.000000 | 否 |

### 1.2 Holm（m=4, α=0.05）在 n=6 下能否通过

Holm 首道门槛 = α/4 = **0.0125**；其后 0.01667 / 0.025 / 0.05。
n=6 双侧符号检验的**全局最小可达 p = 0.03125 > 0.0125** ⇒ 首道门槛
**任何结果组合都不可能通过**，step-down 在第一 comparison 即停止。
最优情形演示（四项比较全部 6/6 同向）：原始 p 全部 = 0.03125，
Holm 校正后全部 = 0.125 → **拒绝数 = 0**。

若各比较的非平局题数不同（n_i = 该比较中 d_i≠0 的问题数），最小可达
p 只会更大（n=5 → 0.0625，连未校正 0.05 都过不了），结论不变且更严。

### 1.3 需要多大信息题数

- 通过未校正 0.05：需 n ≥ 6 且 6/6 全同向（p=0.03125）。
- 通过 Holm 首门槛（0.0125）：需 n ≥ 8（2/256=0.0078）。
- 本数据集只有 6 个问题 ⇒ **确认性检验在当前预算下数学上不可能**。

### 1.4 v2 预注册中的既有错误（必须修正）

v2 §3 原文："仅当 ≥5/6 对同向分歧才可能达 α=0.05（单侧 p=0.0156×2 边界）"
——**错误**。5/6 的双侧 p=0.219，远大于 0.05；唯一能过未校正 0.05 的
是 6/6（p=0.031）。该句把单侧尾概率与双侧 p 混淆，且 5/6 的正确双侧值
使"主结论需 Holm 后 p<0.05"的可满足性为零（见 1.2）。

## 3. 必须修订的问题（按严重度）

**M1（致命）：确认性框架自相矛盾。** v2 同时承诺"主结论需 Holm 后
p<0.05"与 n=6 问题级符号检验——前者在后者下不可能满足（1.2）。
任何"校正后显著"的结果都不存在；保留该判据会使预注册在数学上
不可满足，等于预先注定"无改善"结论——这本身是对新机制的系统性偏见。

**M2（错误陈述）：1.4 的功效声明数字错误**（5/6 双侧 p=0.219 非 0.05
边界），且"方向一致 / 未校正显著 / 校正后显著"三件事必须分开报告：
方向一致性（k/6 同向）本身是合法的探索性证据强度指标。

**M3（区间方法不匹配）**：v2 的"Wilson 差值区间"不适用于本设计。
Wilson 是单比例区间；两独立比例之差用 Newcombe；而本设计是**配对**
（同 6 题两臂）且问题级聚类。配对二元数据的合规描述：
(a) 逐题配对三元组（两臂结果 + 方向）全部列出；
(b) 非平局题中倾向新臂的比例 k/n_disc 的精确（Clopper-Pearson）CI；
(c) 各臂 run 级率可用 Wilson 单独描述（不作差值区间）。
更换理由是配对结构的统计正确性，不是结果好坏。

**M4（多数票平票规则缺失）**：exact_success 为二元，5 个有效种子必有
严格多数；但基础设施失败把有效 run 数降到偶数（如 4 个有效、2:2）时
可能平票。需预注册补一条确定性规则：严格多数定臂级结果；
有效 run 数为偶且平票 ⇒ 该题记 d_i=0（"该题不可判定"），并单独计数
报告。平票不得随机破缺、不得按倾向补判。

**M5（措辞）**：即便走探索性路线，"n=6 未达显著"也**不得**写成
"证明无效果"；方向一致性、效应点估计与 CI 只支持"证据强度"表述。

## 4. 建议的实验定位（选项 A/B/C 比较）

- **选项 A（建议采纳）：保留现有数据规模，定位为探索性机制实验。**
  报告重心改为：逐题配对结果表（6 题 × 4 主对比的方向）、方向一致性
  （k/6）、效应点估计与 M3 修订后的 CI、种子不一致率（稳定性）、
  A/B/C/D 四阶段诊断。精确 p 值照算并如实列出，但**不作为"显著/不显著"
  的确认性语言**；预注册主判据改为"20pp 实际门槛 + 方向一致性 ≥5/6"
  的**联合探索性判据**，明确标注探索性。代价：不能做任何确证性宣称；
  收益：数学上自洽，不预设失败，保留全部诊断价值。
- **选项 B（重新论证样本）：要过 Holm 首门槛需 ≥8 个信息题，考虑平票
  实际需 10–12 题以上**——意味着扩数据集与预算，属新实验设计，本轮
  不得自行执行；若未来走此路需重开预注册 v3。
- **选项 C（其他）**：把四项主比较合并为单一预先指定主对比（如仅 A2vsA5）
  以减半多重校正负担——n=6 下最小 p 仍 0.03125 > 任何含校正的门槛，
  **不解决问题**，不推荐。另一变体：以 A 阶段/B 阶段的机制指标
  （事实可表达性/检索命中/序列化重构率，均为确定性量）作为主结果、
  LLM 行为作为附属描述——统计上最干净，但改变了任务的重心定义，
  应由任务所有者裁决，本审查仅指出该选项存在。
