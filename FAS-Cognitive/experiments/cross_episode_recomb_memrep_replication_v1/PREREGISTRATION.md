## 0. 两个研究问题（分离，不相互替代）

- **RQ-B（检索）**：检索阶段能否找到相关记忆？由 A1（忠实域）的阶段 B
  判定呈现（原机制探针数据：G3 spread top8=[厨房,苹果]，判定"否"）。
- **RQ-RS（给定检索，表示与序列化）**：在相关记忆已进入工作集的条件下
  （人为构造的 R2 情节新近域），表示与序列化是否帮助 LLM 正确重构事实？
  由 A2–A5 回答。
  **结论边界**：RQ-RS 的任何结果只推广到"预先定义的检索条件"（R2），
  不支持"真实/自然检索能力已改善"的宣称；R2 点火集=全部 13 个事件节点
  均匀点火，与问题无关、不含任何未经经历支持的目标结论（无泄漏）。

允许的五种结论（同等合法）：显著改善 / 有趋势但证据不足 / 无改善 / 退化 /
实验无效或无法判定。历史负结果（G3 0/30 等）原样保留。

## 3. 统计设计（探索性；聚类感知）

**调用数 ≠ 独立样本量**：R2 域各臂上下文由 (问题, 臂) 唯一决定，
temperature=0 下同上下文答案视为确定；种子重复仅实测运行稳定性。
**独立推断单位 = 问题级配对（n=6）**。

### 3.1 多数票与平票/无效规则（预注册锁定，不得看结果后调整）

- 评分器 exact_success 为二元（0/1，原 check_answer 逐字复用）。
- 每题每臂 5 次种子调用 → **臂级题结果 = 严格多数票**（≥3/5 为 1）。
- 无效调用（重试耗尽）记 0 分并标 error，计入分母参与多数票；无效数
  单独报告。若有效 run 数为偶且恰好平票（如 4 有效 2:2）→ 该题该臂记
  **"不可判定"**，涉及该臂的配对该题 d=0，单独计数报告；不随机破缺、
  不按倾向补判。缺失评分同无效处理。**不得看结果后排除题目或更换汇总规则**。
- 种子不一致率（同题同臂 5 次结果的分歧比例）单独报告，作运行稳定性
  指标；重复运行不得视为独立问题样本。
- **含义声明（端到端度量，G2）**：无效调用计 0 票使多数票主结果度量的是
  **端到端运行成功与回答正确的结合**，不能解释为纯粹的记忆机制效应。
  各臂必须按三类单独报告：基础设施失败 / 正常返回但答错 / 正常返回且
  答对；原始日志的 error 字段与空回答**原样保留**，不得把基础设施错误
  改写成普通错误答案。基础设施错误引发的缺失/不可判定按 §3.2 的 N
  规则处理；基础设施错误**不计入** D 阶段"LLM 推理失败"（标为 D 不适用
  /因基础设施错误无法评估）。仍须报告端到端主结果（不得只报成功调用
  子集的表现）；**不得在看到实验结果后**临时排除失败调用、改用成功调用
  子集作为主指标或更改重试次数。

### 3.2 联合探索性信号（替代原 Holm 主判据；两者同时满足才称
"达到预先定义的探索性信号"，**不得**称为统计显著或已证实机制有效）

定义（对每项主对比 H1–H4，"新侧"=对比中代表新机制的臂；
**有效题目集合 = 两臂均可判定的题目，N = 其数量；无不可判定题时 N=6**）：
- **问题级准确率差 Δ** = (新侧获胜题数 − 旧侧获胜题数) / N × 100 个
  百分点。两臂均对/均错的有效题**保留在分母**、不计入任一侧获胜题数。
  正号=新侧更优。
- **方向一致性 C** = 新侧获胜题数 / N（统计审查报告 §4 选项 A 的
  "k/6 同向"同族定义，分母由 6 推广为 N）。两臂结果一致的有效题计入
  分母、不计入分子。C≥5/6 门槛保持不变，但**作用于有效题目集合**；
  5/6 只在此意义下计数，**不是显著性阈值**。
- **不可判定题（G1）**：任一臂不可判定的题从 Δ 与 C 的**共同分母**中
  剔除，剔除数量与原因（按基础设施失败类型）单独报告；同时报告原始
  六题覆盖情况与 N——**不得借剔除隐藏实验缺陷**。N=0 ⇒ Δ、C 记为
  不可计算，**不得**判定达到联合探索性信号。
- **联合探索性信号** = Δ ≥ 20 个百分点 **且** C ≥ 5/6（均在有效题目
  集合上计算）。达到 ⇒ 报告"达到预先定义的探索性信号"；任一不满足 ⇒
  报告"未达到联合探索性信号"，同时如实呈现 Δ、C、N、剔除数、逐题
  结果与可用区间。**N<6 时**结果只能按探索性描述解释，不得宣称达到
  确认性证据标准。联合探索性信号始终是探索性指标，不是统计显著性
  或机制有效性的证明。

### 3.3 检验与区间（各回答什么问题）

- **精确符号检验（双侧，n=非平局题数）**：对 H1–H4 照算并如实报告
  p 值，**仅作参考描述**——n=6 全局最小 p=0.03125（6/6），5/6 即为
  0.219；不含多重校正的 p 值不构成"显著"宣称。Holm 校正后 p 可附报，
  但须注明其在本设计下恒不可拒绝（最小 p 0.03125 > 首门槛 0.0125），
  保留仅为与 v2 判据的可比性。
- **逐题配对表（主报告物）**：每题两臂多数票状态（对/错/不可判定）+
  差异方向，全量列出。
- **非平局方向比例的精确区间**：对每项主对比，取非平局题中倾向新侧的
  比例 k/n_disc，给 Clopper–Pearson 精确 CI；**含义标注**：它描述
  "信息题中方向比例"，**不是**总体准确率差的置信区间。
- **各臂 run 级率与 Wilson 区间**：仅描述各臂自身 30 run 的正确率，
  **不得**冒充问题级配对效应区间。
- **配对准确率差 Δ 的区间**：本轮**不提供经验证的配对差区间**（n=6 聚类
  下无既定已验证方法，不为填表使用错误方法）；以逐题表 + Δ 点估计 +
  3.3 上述区间合力呈现证据强度。
- 复用与变更记录：评分器/任务/问题/配对结构沿用原实验；本轮变更
  （探索性定位、判据替换、区间方法）全部登记于版本记录，未查看任何
  正式结果。

## 4. A1 与 harness 等价性（不重跑历史实验）

A1 = **旧路径行为参照（负对照）**。因 max_tokens=400（原 300）与模型
版本漂移，A1 不宣称与原始实验严格等价。

实际核对过的等价项：数据集/问题/图为同一原档文件；提示词模板与评分器
逐字移植（diff 留档）；FAS 管线逐字段一致（weight=1.0 节点、
activate_from_inputs(seeds)、diffuse_round(max_steps=4)、get_topk(8)、
ids+Relations ≤10 条格式）；配对结构 (question, seed∈{0..4})。
**残余差异（声明）**：max_tokens、模型版本（mimo-v2.6-flash）、调用直连
openai 客户端（后端配置同 v2.LLMHead）、独立执行目录。A1 与历史数字的
相似度只作方向性参照，不作等价性证明。

## 5. 逐 run 日志与 A/B/C/D 四阶段判定（可审计）

每次调用保存：臂配置快照（图 JSON 哈希、rep_fix 开关、点火集、代码
commit）、Top-k 节点 id+激活值、序列化全文、完整 prompt、原始回答全文、
评分分项、错误与重试记录。

四阶段逐 run 判定（诊断框架，非预定结论；前提未满足时后续阶段记
"不适用"，不得把下游失败归因于目标机制）：
- **A（事实在图）**：gold 三元组在所选图表示中可表达？（G3 原样=0，
  rep_fix=1。）
- **B（检索命中）**：gold 链实体/事件节点是否进 Top-k（含激活值）？
- **C（序列化保留）**：上下文文本中可重构的 gold 三元组数（确定性
  子串检查，含方向词）。
- **D（LLM 重构）**：exact/partial/路径有效性 + 原始回答。
互斥分类：A=0 ⇒ "表示不可表达"（后续不适用）；A=1∧B=0 ⇒ 检索失败；
B=1∧C<应有 ⇒ 序列化失败；C 齐备∧D=0 ⇒ 推理/评分复核（人工复核记录
留档）。

## 6. 预算、停止与无效运行

上限 210 次成功调用（7 臂×30）+ 每调用 ≤3 次指数退避重试。无效判据：
单臂连续 ≥5 次调用失败或错误率 >30% → 暂停该臂、留档、登记偏离；
修复后仅重跑受影响臂（失败记录保留为 invalid 段）。修复不得触碰提示词/
模型/数据/评分器/点火集。预注册未覆盖情形 → 暂停并登记 ADDENDUM 或 v4。
**无基于结果的提前停止**；跑满或预算耗尽即停。

## 7. 结果解释规则（探索性定位的落点）

- 达到联合探索性信号 ⇒ "在预先定义的探索性判据下观察到与主假设一致的
  信号"，**不得**写"统计显著""已证实机制有效"。与 §0 五种结论的对应：
  本设计下最好情形对应"有趋势但证据不足"一档的强信号；"显著改善"一档
  需要未来具备充分功效的确证性实验（如 ≥8–12 信息题的重新设计），
  本实验**结构上不可能**给出该档结论。
- 未达到 ⇒ "未达到联合探索性信号"，同时完整呈现 Δ、C、逐题表、方向
  比例 CI；**不得**写"证明无效果"。
- 全部结论限于：本数据集 6 题、R2 检索条件、本 harness；不推广到
  FAS 整体能力或生产环境。
- 历史失败实验的负结果与本实验结果严格分开归档，不互相改写。
