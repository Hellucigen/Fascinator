# 宣传素材清单（视频拍摄用）

## 镜头 1：凌晨自主早安（核心卖点）
- 素材：logs/runtime.log 中 `主动表达: CI_… → 早安。` 与
  `delivery_settled … success: true`（07:09）；前一夜的告别授权日志
  （`告别授权：好奇心信号 +995min`）
- 展示逻辑：前一晚说晚安+授权 → 早上她自主开口——配日志逐行讲
  "这不是 cron，是社交驱力涨满走出来的"
- 可复现：再说一次"晚安，电脑不关你随便玩"，等次日早晨

## 镜头 2：她知道自己猜的是猜的
- 素材：data/task_workspace 的假设调研台账；假节点实验：
  喂一个假概念 → 观察假设节点（置信 0.3）→ 调研 → 证实/证伪
- 展示逻辑：推测与事实在图上有类型分界（hypothesis_leg 无证据不强化）

## 镜头 3：满足语义看得见
- 素材：runtime.log 的种子轮换（特斯拉→微软，bing 命中行）+
  兴趣水位（note_interest searched）+ 4h 近访排除
- 展示逻辑：调研过会降温、会轮换——不是无脑重复刷同一话题

## 镜头 4（可选）：认知观察面板
- 素材：Charon Haru 模块认知抽屉（当前意图/活跃概念/活动账本）
  或网页版 http://127.0.0.1:5000/
- 展示逻辑：所有面板数据是真实运行状态，无编造
