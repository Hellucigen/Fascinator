## 2. 新增的关系表达（全部复用 graph_schema 规范本体 104 词，零新关系词发明）

`是 / 属于 / 包含 / 组成部分 / 具有 / 作用于 / 使用 / 需要 / 发生于 / 诱发 / 影响 / 可实现为 / 先于 / 针对 / 关于 / 相关 / 实例属于 / 经历 / 喜欢`
**认识论三层**（每条边/节点带标注，不混用）：
- `epistemic=general`（世界常识）：歌词—针对—离别
- `certainty=likely`（统计倾向，**绝不写成"导致"**）：慢歌—诱发—平静、音乐—影响—专注提升
- `type=episode`（运行时个人经历）：由既有事件/偏好机制写入，pack 只给锚类（个人音乐记忆/喜欢的歌）
区分"作品表达的情绪"（歌词—针对—思念）与"听者感受的情绪"（慢歌—诱发—感伤 likely）与"具体用户的实际感受"（运行时事件）——同一歌曲三层各自成立。

## 3. 修复的真实断点（发现→修复→证据）

1. **[生产断点] 知识包从未被加载**：`get_pack_manager()` 默认扫 companion 仓 `knowledge_packs/`（空目录），认知仓 3 个包躺了两周没进过图。修：单例支持传根 + app 指向认知仓。启动日志实证 5 packs 全载。
2. **[生成器缺陷，副本验收抓到] pack 引用 runtime 节点的边被当悬空丢弃**（"跳过已有节点"的对齐直觉是错的——pack 先于 runtime 加载）。修：全量携带 + overlay 覆盖归一；慢歌→平静 等 5+ 跨域边复活。
3. **[语义断链，V1b 抓到] 老歌/怀旧效应与个人音乐记忆不连通**——补 怀旧效应—关于—个人音乐记忆、老歌—影响—喜欢的歌(likely)、个人音乐记忆—包含—喜欢的歌。
4. **[写入垃圾源头] vision 未命名占位符（UnknownObject*）入图**（13 节点实锤孤岛）→ 桥接层过滤：未命名检测碎片不再进图，命名后照常。
5. **[表达闸] pack 节点零激活+低权重**（V7 断言）：知识入图 ≠ 想说话，不污染主动表达决策。

## 4. 音乐—情绪—个人经历实际图谱路径（副本 BFS+扩散双验证）

- 慢歌 —(诱发 likely)→ 平静/感伤 —(相关)→ 难过/思念；慢歌 —(影响)→ 入睡困难缓解；
- 睡前 —(听音乐发生于场景链)→ 听音乐 —(作用于)→ 情绪调节 —(可实现为)→ 听音乐；
- 老歌 —(诱发 likely)→ 记忆唤起 —(关于)→ **个人音乐记忆** —(包含)→ 喜欢的歌；
- **真实扩散测试**：种子"慢歌" activate + diffuse_step×4 → 点亮 9 节点（速度_音乐/平静/感伤/入睡困难缓解…），**有界不炸网**、seed 未被"用户/Self"枢纽夺走；
- **方向纪律**：种子"平静"（边的被指向端）正向 2 跳**不回溯点亮"慢歌"**——forward 语义生效，"不应传播的不传播"成立。

## 7. 仍然存在的问题（不藏）

1. **跨空间桥的账**：cognitive↔episodic 桥仍只有 10 条（modulator 子图与情景记忆基本不互达）——pack 补的是语义层联通，**情绪调制器与个人经历的关联**要等消费侧接线（reflection/temporal 写事件边），属下一轮。
2. components 62→73：pack 子图经 9 条桥并入主分量后，仍有 life 包部分链悬在桥外（桥锚点被遗忘机制清出，7 条 skip）——随使用会长合；无意义硬连不做。
3. 音乐 pack 是**结构骨架**（概念层级+关系+认识论标注），不是曲目知识库——具体歌曲的常识（歌手/年代表）需要外部数据源授权后按同一生成器管道导入（来源/版本/许可三字段格式已就绪）。
4. V3 的方向验证基于 pack 内 forward 边；存量 1203 条历史边里的方向错误**未做批量修正**（任务书禁止未验证的不可逆批量改写）——doctor 报告里 terminals_only_in 99→146 提示后续值得审。
5. 知识包节点与运行时 LLM 抽取产物的**别名归一**（compound_phrase_handler/synonym_map）没有覆盖音乐域新词——首见同义词会先建新点再靠 merge 归一，属可接受次优。
