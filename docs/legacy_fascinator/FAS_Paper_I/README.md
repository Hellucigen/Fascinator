# FAS Paper-I — Final Manuscript Package

Evidence-first rebuild of the Fascinator Paper-I. Every number in both manuscripts is programmatically extracted from archived raw experiment runs.

## Contents
- `main.tex` / `main.pdf` — English manuscript (submission version)
- `main_zh.tex` / `main_zh.pdf` — Chinese parallel manuscript (content/numbers/claims identical)
- `references.bib` — all citations (real sources only)
- `figures/` — 8 vector PDF figures, generated by `paper_audit/gen_figures.py` from the fact database
- `PAPER_FACT_DATABASE.json` (copy) — machine-extracted facts; single source of every number
- `CLAIM_EVIDENCE_MATRIX.md` — claim → evidence map with per-claim caveats
- `PAPER_IMPLEMENTATION_DIFF.md` — old-paper vs current-system discrepancy matrix
- `PROJECT_ARCHITECTURE_MAP.md` — call-chain-verified component status
- `FINAL_REVIEW.md` — three-reviewer reverse review
- `REPRODUCIBILITY.md` — protocol, seeds, archive layout, reproduction entry points
- `TERM_GLOSSARY.md` — CN/EN term mapping enforced across both manuscripts

## Building
```
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
pdflatex main_zh.tex && bibtex main_zh && pdflatex main_zh.tex && pdflatex main_zh.tex
```
Portable MiKTeX used for this build; ctex auto-installs for the Chinese version.
