# DESIGN — shared-hub 参数扫描(shared-hub parameter sweep)

日期:2026-10-01(运行前冻结;运行后不得修改假设/条件/样本量/检验,只能追加结果)。
状态:**设计冻结 → 执行**。

## 1. 假设(预注册)

背景:预注册机制战役(CIV)中 H3(FAS 的 JCG 优于 flat)被拒(0/200 反超);唯一系统性正差分出现在组合拓扑 O3(共享枢纽,FAS 30/30 vs B2 0/30),但仅单一权重配置 w=0.5。本扫描回答:**FAS>flat 的优势区在 (权重 w, 汇聚输入数 k, 路径深度 d) 空间中位于何处、有多大**。

- H-A(主假设):存在非空的 (w,k,d) 区域使 FAS 联合目标 Top-1 命中率显著高于 B2;该区域随 k 增大而扩大,随 w 增大而收缩。
- H-B:FAS 优势随深度 d 增大而衰减(扩散稀释),B2 乘积同样衰减,但两者衰减速率不同。
- H-C(连接性):在 O3 复现格(w=0.5, k=2, d=1, 无干扰项)上,FAS 30/30 可复现(preflight 硬判据)。

失败判据:若所有 84 格的配对差均为零或负(H-A 不成立),如实报告为"未找到 FAS>flat 的参数区",论文相应表述回退为"单一格正差未获参数扫描支持"。

## 2. 条件(冻结)

参数化共享枢纽拓扑(每格每种子重新生成,确定性):

- 输入 I_0..I_{k-1},k ∈ {2,3,4,6}。
- 枢纽路径:输入 i 经 d 跳私有中间节点(m_{i,1..d},每跳边权 w)到枢纽 H,再经 1 跳(w)到联合目标 T。联合跳数 joint_hops = d+2,d ∈ {0,1,2}(d=0 即输入直达枢纽,复刻 O3)。
  [修订 v1.1,2026-10-01,首次运行 preflight 失败后、任何正式数据产生前:初稿把 d 误定义为"枢纽到目标的跳数",导致 O3 复现格 (w=0.5,k=2) 不在任何格内,preflight 硬判据失败。现按 O3 结构把 d 重定义为私有中间跳数并取 {0,1,2};假设/检验/样本量不变。]
- 单跳对照(single targets):每个输入 i 经 2 跳(边权 0.8/0.8,固定,复刻 O3 的分支强度)到单目标 S_i。 singles 是 B2 在无汇聚时的自然答案。
- 干扰项:每个输入挂 4 个 2 跳干扰候选(边权 0.3),干扰候选不进 candidates 排名域,只作为扩散稀释源;候选域 = {T} ∪ singles ∪ {10 个干扰候选}。
- 每格内所有种子共享同一 w/k/d;种子池 = {1..30}(30 配对种子/格,预先固定)。
- 网格:w ∈ {0.3,0.4,0.5,0.6,0.7,0.8,0.9} × k ∈ {2,3,4,6} × d ∈ {1,2,3} = 84 格。
- 附加格:O3-replication(w=0.5,k=2,d=1,无干扰项、候选域={T,S_0,S_1},权重与 generator.combo_task 完全一致)用于 preflight 连接性检验。

## 3. 方法与预算相等(冻结)

与 CIV 相同五方法框架,本扫描只报告 FAS / B2(主对比)与 B1(直注入,完整性):

- FAS:generator.Graph.diffuse_round(steps = joint_hops+2, seed_strength=5.0, ratio=0.5, transfer=1.0, beta=1.0, gain=1.0, decay=0.05, cap=5.0)。
- B2:闭式最优路径乘积之和(max_len = joint_hops+2)。**B2 是同结构信息的闭式近似,不是 embedding 检索**(正文表述由本轮改写明确)。
- B1:直接出边权重和。
- 输入子集:multi(全部 k 个输入)与 each-single(单输入);JCG = score(T|multi) − mean_i score(T|single_i)。
- tie-break:与 CIV 相同的 per-seed 固定洗牌。

## 4. 样本量与检验(冻结)

- 每格 30 配对种子;主指标 success@1(T 排第 1,取值 0/1);次指标 MRR;第三 JCG。
- 每格检验:success@1 用配对精确 McNemar;MRR 用双侧配对 Wilcoxon。**本扫描定位为描述性(探索性)参数曲面**,不做全域多重校正;论文正文只引用"符号一致"的格计数与曲面形状,不对单格 p 做确认性主张;凡引用单格差,注明"探索性,未校正"。
- 汇总统计:(a) FAS>B2 严格的格数/84 及其在 (w,k,d) 中的分布;(b) w 阈值行为(两法 MRR 同时跳变的权重);(c) k 的边际效应(FAS−B2 差的中位数随 k);(d) d 的边际效应。
