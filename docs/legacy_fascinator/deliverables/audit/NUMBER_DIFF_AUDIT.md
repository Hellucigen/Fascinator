## 结论

### 消失的数值(旧 main 有、新 main 无)
- **174/211 种被补充材料逐字承接**(组件状态表、RQ 映射、路由全表、关系方向全数据、审计表、族溯源表、案例研究图、配置清单等整体迁入 S1–S14)。
- 其余为多集计数残差与杂项,逐类核实:
  - **TikZ 排版坐标**(如 −0.354、1.646、−2.42、5.25):旧图布局参数;新图有新坐标(见下),非论文主张。
  - **千分位拆分**:'34'+'016'(旧写法 `34{,}016`)≡ 新写法 34,016。
  - **重复出现合并**:旧稿同一数字在正文+多表重复 2–4 次;新版集中出现 1–2 次(如 61.5/16.6/45.8/17.2 在主文一次 + 补充材料一次)。
  - **引用键中的年份**(\citep 键 yao2023react 等)与页码类噪声。
- **无任何论文主张级数字消失**。

### 新增的数值(新 main/supp 有、旧 main 无)
- **阶段四新实验(唯一允许的新增来源)**:

- **新图 fig_sweep 的坐标/字号参数**与**新引用键年份**:排版/文献杂项。
- **无任何未经实验来源的新增声称数字**。

### ZH 镜像一致性
