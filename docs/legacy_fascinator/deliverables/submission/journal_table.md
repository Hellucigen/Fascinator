## 推荐排序(按本文匹配度)
1. **IEEE TCDS** — 认知架构+具身系统最对口;负结果与预注册协议在系统类期刊中是差异化优势。
2. **JAAMAS** — 智能体记忆与知识表示受众;Springer 单栏长文对本文篇幅友好。
3. **JAIR** — 免费、严谨声誉高;对协议与负结果的呈现要求最高(本文已具备)。
4. **Adaptive Behavior** — 行为层读者;需在引言强化行为相关性。
5. **Neurocomputing** — 体量大、周期较快;范围匹配弱于前四。
